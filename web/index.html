脚本 API 说明 
可用参数：
  req      可修改：{ method, url, headers[], query[], bodyType, body, formFields[] }
  vars     全局变量：get(key) / set(key, value) / remove(key) / all()
  console  log / warn / error，最多保留 2000 行，输出见响应区「脚本输出」页

执行顺序：前置脚本 → {{变量}} 替换 → 发送
修改 req.url 的查询串会覆盖 Params 表（URL 优先）；只改参数请修改 req.query
示例：req.headers.push({ key: 'X-Token', value: vars.get('token'), enabled: true });
注意：脚本同步执行，死循环会卡住页面；脚本仅本人编写，响应数据经参数传入
脚本 API 说明 
可用参数：
  res      只读：status / statusText / headers[] / getHeader(name) / bodyText
           timeMs / sizeBytes / finalUrl / truncated
           res.json() → 无损解析，大整数为 LosslessNumber，String(x) 取精确文本
  vars     get / set / remove / all，set 后自动持久化
  console  log / warn / error

示例：
  const data = res.json();
  vars.set('token', data.token);
  vars.set('orderId', String(data.orderId));  // long 精确转字符串
  console.log('status', res.status);
