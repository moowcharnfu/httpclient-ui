# 安全说明

## 1. 安全目标

HTTP Test 用于访问用户主动指定的 HTTP API，包括本机、内网和公网服务。它的安全目标是：

- 不向本机意外开放可由第三方网页驱动的 HTTP 管理端口。
- 不向 WebView 开放任意文件系统、Shell 或进程执行权限。
- 限制单请求、批量、响应和并发任务造成的资源耗尽。
- 明确保存数据、用户脚本、证书校验和发布签名的风险。
- 让取消、退出和错误处理有可观察的结果。

本工具不是沙箱，也不是生产密钥管理器。

## 2. 架构与信任边界

```text
WebView 页面
  → Tauri IPC
  → Rust 命令校验
  → reqwest
  → 用户指定的目标 HTTP API
```

### 受信任内容

- 应用自身的前端和 Rust 代码。
- 用户编写并主动执行的前置/后置脚本。
- 用户导入的变量 JSON。
- 用户主动粘贴的 cURL 文本；其内容仍按不可信输入解析，不作为命令执行。

### 不受信任内容

- 目标 API 返回的响应体、Header、重定向地址和图片。
- 用户误打开的非可信脚本。
- 第三方安装包、更新包或伪造下载源。

响应文本通过 DOM 文本节点展示，不直接作为 HTML 执行。JSON 解析器对 `__proto__` 使用自有属性定义，避免该键触发原型赋值。

## 3. 不监听本地端口

生产代码没有 `TcpListener`、Axum 服务或 `fetch('/api')`。前端使用：

```js
window.__TAURI__.core.invoke(...)
```

网络连接只由 Rust 的 reqwest 客户端发往用户填写的目标地址。单元测试可以使用本地 TCP 夹具，但测试监听器不会进入生产二进制。

因此关闭防火墙不会阻止 HTTP Test 工作，也不需要为它新增入站规则。

## 4. Tauri 权限

`server/capabilities/default.json` 只向 `main` 窗口授予 `core:default`。应用自身页面可调用以下四个 Tauri 命令；Rust 命令由 `generate_handler!` 注册，不额外开放浏览器跨域访问：

- `send_request`
- `batch_request`
- `cancel_job`
- `exit_app`

未启用以下能力：

- 任意文件系统读写；
- 任意 Shell 执行；
- 任意进程启动；
- 对话框或系统路径遍历；
- 远程更新自动执行。

文件由用户通过文件输入控件选择。读取和编码发生在 WebView 前端，Rust 不接收任意本地路径。

## 5. CSP 与脚本

当前 CSP 允许：

```text
script-src 'self' 'unsafe-eval'
```

原因是前置/后置脚本使用 `new Function` 执行。该设置意味着：

- 用户脚本与页面脚本具有相同来源和大部分页面能力。
- 恶意脚本可能读取页面状态、localStorage、变量，并主动调用 IPC 命令。
- 脚本沙箱隔离尚未实现。

只执行自己编写或已审查的脚本。不要在脚本中硬编码生产密钥。

脚本同步执行，死循环或超长计算会冻结 WebView。当前没有 Worker 隔离或执行超时，这是已知限制。

## 6. 本地存储

草稿、历史和变量保存在应用 WebView 的 localStorage：

- 未加密；
- 可能包含 Authorization Header、Cookie、Token、URL 参数和响应正文；
- 容量由平台和 WebView 决定；
- 写入失败时会提示，但不会自动转存到其他位置。

建议：

- 不在变量或草稿中长期保存生产密钥。
- 使用测试环境凭证。
- 敏感测试结束后清空变量和历史，或使用系统功能清理应用数据。
- 备份导出的变量 JSON 时按敏感文件处理。

## 7. cURL 导入边界

cURL 导入完全发生在 WebView 前端：

- 不调用系统 curl、Shell、子进程或文件读取 API；
- 只实现受限的引号与转义解析，不执行任何导入文本；
- 拒绝未引用的 `;|&<>()`、双引号或未引用文本中的 `$(...)` 和反引号；单引号内容按字面量保留；
- 拒绝 `@file`、multipart、文件上传、输出文件、配置文件、证书文件、多 URL 和未知选项；
- 不展开 `$NAME` 等 Shell 变量，保留原文并提示；
- 命令限制为 1MB、4096 个参数，查询参数最多 4096 个。

导入仍会填充 Authorization、Cookie、URL 参数和 Body，随后按现有草稿逻辑写入明文 localStorage。不要从不可信来源直接导入含生产凭证的命令。解析器只覆盖文档列出的 curl 子集，不保证复现全部 curl 行为。

## 8. 网络行为

- 只允许 `http` 和 `https` URL。
- 默认跟随重定向，最多 10 次。
- 默认校验证书。
- “忽略证书”会跳过 TLS 校验，仅用于受控自签名测试。
- 应用不会阻止访问本机、内网、云元数据地址或其他用户主动填写的目标。

因为这是用户驱动的 HTTP 客户端，没有通用 SSRF 黑名单。不要在执行不可信脚本时向其开放生产网络。

## 9. 文件与请求内存

默认限制：

- 单文件 1MB；
- 可配置单文件上限 128MB；
- multipart 文件合计 160MB；
- IPC JSON 256MB；
- 单请求逻辑输入 256MB；
- 单响应保留 32MB；
- 活动任务 32；
- 请求工作预算 768MB，按 IPC 字节数 × 3 估算；
- 响应工作预算 768MB，单请求按 96MB、批量按 64MB 估算预留。

文件会经过 Data URL、Base64、JSON、IPC、Rust 解码和请求体，存在多份副本。预算不是操作系统级内存硬上限；Tauri 在命令执行前已经接收的 IPC 字符串、命令返回后的 IPC 序列化，以及 WebView 解码副本不受 Rust guard 直接约束。响应固定预留会限制同时运行的大响应任务，小响应也可能被其他任务的估算预留拒绝；该预算不是物理内存硬上限。

不要在高负载生产主机上把上限调到最大。低内存设备应保持默认 1MB。

## 10. 取消语义

取消覆盖：

- 等待连接；
- 请求发送；
- 响应流读取；
- 批量轮间隔；
- 下一轮批量请求。

不能强制中断的阶段：

- 大型 JSON 字符串解析；
- Base64 解码；
- multipart 边界和 Body 组装；
- 某些同步系统调用。

这些阶段运行在阻塞线程中。取消信号会在阶段完成后被检查，因此“点击取消”不保证立即停止 CPU 工作。网络请求本身会被取消，不会留下 HTTP Test 管理的后台请求任务。

## 11. 响应与解析

- 单响应最多读取 32MB；批量样本每份最多保留 512KB，达到上限或批次共享 16MB 预算耗尽后停止读取。
- `sizeBytes` 统一表示实际保留字节数；批量明细的 `truncated` 标记因上限停止读取，恰好等于上限时也可能为 `true`。
- 响应体会在解压后按字节上限读取；压缩比极高的大型响应仍可能消耗 CPU 和网络带宽。
- JSON 解析最大深度 512。
- 可视化树最多渲染 200000 节点。
- 差异最多显示 2000 条。
- 大整数按原始文本保存，避免 JavaScript Number 精度损失。

## 12. 安装包与发布信任

- Windows 正式分发应使用 Authenticode 签名和时间戳；未签名包可能触发 SmartScreen。
- macOS 正式分发应使用 Developer ID 签名、Hardened Runtime 和 Apple 公证。
- Linux 包签名取决于分发仓库；直接下载的包需要用户校验来源和哈希。
- 签名证明来源和完整性，不代表应用没有漏洞。
- 不要通过关闭 SmartScreen、Gatekeeper 或系统安全功能来解决发布问题。

详见 [构建与安装](BUILD.md)。

## 13. 已知残余风险

| 风险 | 当前处理 | 残余 |
| --- | --- | --- |
| 大 IPC 字符串并发峰值 | 256MB 单请求、768MB 请求预算、768MB 响应预算、32 任务上限 | IPC 调用前字符串和返回后序列化不受 Rust guard 直接限制 |
| CPU 预处理不可立即取消 | 预处理前后检查取消 | JSON/Base64/multipart 当前阻塞步骤会继续完成 |
| 用户脚本权限过大 | 仅允许可信脚本、CSP 收紧其他来源 | `unsafe-eval` 和无 Worker 隔离 |
| localStorage 明文 | 文档提示、限制历史条数 | 未加密，仍可能含敏感数据 |
| 脚本死循环 | 异常捕获 | 无执行超时，可能冻结页面 |
| 自签名证书 | 默认校验、显式忽略开关 | 用户主动开启后会失去 TLS 身份保证 |
| 响应资源耗尽 | 字节上限、批量共享预算 | 头部、解压 CPU 和 WebView DOM 仍受平台限制 |
| 目标网络风险 | 仅 http/https、重定向上限 | 有意支持内网和本机，不做 SSRF 黑名单 |

这些项目应在后续版本通过独立脚本沙箱、流式 IPC、可中断预处理和加密存储逐步收敛。
