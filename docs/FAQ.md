# 常见问题

## 应用启动

### Linux 提示缺少 WebKitGTK 或 GTK

HTTP Test 使用 WebKitGTK 4.1 和 GTK 3。安装对应运行库：

```bash
sudo apt install libwebkit2gtk-4.1-0 libgtk-3-0
```

Fedora/RHEL 系包名通常是 `webkit2gtk4.1` 和 `gtk3`。AppImage 不会自动提供 WebKitGTK 4.1。

### Windows 提示未知发布者或 SmartScreen 拦截

本地构建产物可能未签名。只运行可信来源的安装包；正式分发应使用 Authenticode 签名和时间戳。不要为了运行工具而全局关闭 SmartScreen。

### macOS 提示无法验证开发者或应用已损坏

确认安装包来自可信来源。未签名/未公证的开发包可能需要在“系统设置 → 隐私与安全性”中允许，或右键打开。正式分发应完成 Developer ID 签名和公证。

### 为什么不需要开放端口

HTTP Test 不启动本地 Web 服务。WebView 通过 Tauri IPC 调用 Rust，Rust 再连接目标 API。地址栏中的端口是目标 API 的端口。

## 请求发送

### URL 没有协议头会怎样

默认补 `http://`。例如 `example.com/api` 会变成 `http://example.com/api`。需要 HTTPS 时请输入完整地址。

### 变量没有替换

检查：

- 变量是否启用；
- 名称是否完全一致；
- 占位符是否为 `{{名称}}`；
- 是否在“脚本输出”中看到未解析变量告警。

### form-data 的 Content-Type 为什么不能手改

multipart 的 boundary 由请求体决定。手写 boundary 会与 Rust 生成的请求体不一致，因此该模式固定使用 Rust 生成的 Content-Type。

### 为什么请求失败提示 Header 非法

Header 名必须符合 HTTP 规范，Header 值不能包含非法控制字符。检查变量替换后的值，而不是只检查替换前的内容。

### 忽略证书后仍连接失败

忽略证书只跳过 TLS 证书校验，不代表 DNS、端口、代理、协议或服务端配置一定正确。请查看完整错误链。

## cURL 导入

### 如何把浏览器请求转成应用请求

在浏览器开发者工具中选择“复制为 cURL”，打开 HTTP Test 顶部“导入 cURL”，粘贴后点击“解析并导入”。方法、URL、Params、Headers、Body、Basic 认证和常用选项会自动填充，发送前可继续修改。

### 为什么 cURL 导入失败

常见原因：

- 命令不是以 `curl` 开头，包含多条命令或 Shell 管道、重定向；
- 使用了 `$(...)`、反引号等命令替换；
- 包含 `@file`、`-F`、`-T`、输出文件、证书文件或未知选项；
- 引号、转义或 Header 格式不完整；
- 命令超过 1MB 或 4096 个参数。

错误会显示在导入抽屉中。文件请导入后在 Body 区选择，Shell 变量请改为 `{{变量}}` 或手动填写。

### 导入会覆盖脚本吗

不会。导入替换当前请求，但保留前置/后置脚本和单次上传上限。请求或批量运行期间不能导入。

### 为什么导入后没有跟随重定向

curl 默认不跟随重定向，因此未写 `-L/--location` 时导入结果为关闭。应用原请求默认开启，导入后请按目标接口需要调整。

## 文件上传

### 默认只能上传 1MB

这是有意的默认保护。选择 `form-data` 或 `binary` 后，在 Body 区域把“单次上传上限(MB)”调到需要值，再重新选择文件。范围为 1–128MB。

### 调大上限后仍然提示超限

可能原因：

- multipart 文件合计超过 160MB；
- 降低上限后仍保留旧文件，发送前校验失败；
- 请求 JSON 加 Base64 后超过 256MB；
- 输入框值不是 1–128 的整数，已被夹到边界。

### 历史载入后文件丢失

为避免 localStorage 保存大 Base64，历史和草稿只保存文件元数据。载入后重新选择文件即可。

### 为什么大文件可能占用很多内存

文件会经过 Data URL、Base64、JSON、IPC 和 Rust 解码，存在多份副本。默认 1MB 可以显著降低峰值。不要在上限允许时默认选择最大文件。

## 响应与 JSON

### 响应显示不完整

单响应最多保留 32MB。超过后会截断并显示提示。批量样本每份最多保留 512KB，整个批次共享 16MB；达到上限或预算耗尽后停止读取，不再下载剩余 Body，并显示“已达上限”；恰好等于上限时也可能出现该标记。明细“大小”是实际保留字节数，不是完整响应大小。

### 大整数精度正常吗

正常。无损解析器把 JSON 数字保存为原始文本，不经过 JavaScript Number。发送 JSON Body 时也保留原始文本。

### 为什么 1 和 1.0 被判断为值变更

数字按原始文本精确比较，避免浮点误差掩盖差异。若需要数值等价比较，请在目标 API 或后置脚本中归一化。

### 图片不显示

确认响应 Content-Type 是受支持图片类型，并且响应未被截断。Blob 图片受 CSP 的 `img-src data: blob:` 约束。

### 差异对比没有可用记录

只有响应体不超过 512KB 且成功保留原文的历史记录可以参与对比。

## 脚本

### 脚本报错后页面还能用吗

语法错误和运行异常会记录在“脚本输出”中，不会直接中断页面。修正脚本后可再次发送。

### 脚本卡住怎么办

脚本同步执行，当前没有 Worker 隔离或超时。死循环会冻结 WebView，只能结束应用进程。避免在脚本中写无限循环或超长同步计算。

### 批量为什么没执行后置脚本

批量只执行一次前置脚本，用于生成统一模板；后置脚本不执行。需要逐请求断言时请使用单请求循环或外部测试工具。

## 批量与取消

### 批量请求数被拒绝

并发数和轮数都必须在 1–1000，且乘积不超过 1000。请求大小 × 总请求数还不能超过 64MB。

### 点击取消为什么没有立刻停

网络等待、发送、响应读取和轮间隔会及时响应取消。JSON 解析、Base64 解码和 multipart 组装属于 CPU 预处理，需要当前步骤完成后才检查取消。

### 退出后还会有请求继续吗

应用退出流程会先取消所有已注册任务，再退出。CPU 预处理可能延迟到当前步骤结束，但不会留下 HTTP Test 管理的后台请求进程。

## 历史、变量与存储

### 草稿或历史没有保存

localStorage 可能已满或被 WebView 禁用。应用会显示“未持久化”提示。当前会话中的数据仍可使用，但重启后可能丢失。请清理历史或减少大响应记录。

### 变量导出文件包含敏感数据吗

可能。导出文件是明文 JSON，请按敏感文件保存，不要上传到公共仓库或聊天工具。

### 如何清理应用数据

使用操作系统提供的应用数据清理功能，或在应用内清空历史、变量和草稿。不同平台的 WebView 数据目录不同，不建议手工猜测路径后直接删除整个用户目录。

## 构建与发布

### 能在 Windows 上直接构建 macOS 安装包吗

不能可靠地通过一条命令完成。macOS 应用需要 macOS/Xcode 工具链、系统框架、签名和公证环境；Windows 包也应使用原生 Windows/MSVC 环境构建。

### macOS 配了 10.15 就一定能在 10.15 运行吗

不一定。`10.15` 是部署目标，还需要依赖、WebKit 和系统框架共同支持，并应在最低目标系统或接近版本上实测。

### Linux 三个包有什么区别

- deb：适合 Debian/Ubuntu。
- rpm：适合 Fedora/RHEL 等 RPM 系。
- AppImage：免安装单文件，但仍依赖系统 WebKitGTK 4.1。

更多内容见 [构建与安装](BUILD.md) 和 [限制与配置](LIMITS.md)。
